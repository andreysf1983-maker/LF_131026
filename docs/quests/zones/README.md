## How to read a catalog file

- **ID** - `quest_template.ID`
- **Prev / Next** - chain from `quest_template_addon`
- **Patterns** - auto tags ([TAXONOMY.md](../TAXONOMY.md))
- **Provided item** - `StartItem` (capture quests)
- **Script** - custom `QuestScript` if any
