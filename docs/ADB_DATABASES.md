# Чистые ADB-базы world и hotfixes

`setup.bat` больше не просит помещать ваш большой `world.sql` и `hotfixes.sql` в `sql\base`.
Он сначала проверяет, есть ли корректные данные в MySQL. Если обе базы уже готовы, ADB не скачивается.
Если `world` или `hotfixes` пусты, установщик автоматически получает чистую базу.

## Источник и проверка

- Официальный релиз AshamaneCore: [ADB_735.10 Final before BfA](https://github.com/AshamaneProject/AshamaneCore/releases/tag/ADB_735.10).
- Сжатый файл: `ADB_735.10.rar`, 87,997,425 байт (около 84 MiB).
- SHA-256 архива: `e3f0f90db8940f3a1201188fafdf740b8734e2d3e893e1cebbd14c2b9917154a`.
- Перед распаковкой проверяется SHA-256. Распаковщик RARLAB UnRAR также скачивается только с официального сайта и проверяется закреплённым SHA-256.
- **Почему не 7-Zip:** в архиве используется RAR v6 compression method `m3`, который 7-Zip может показать в списке, но не распаковывает. Установщик использует RARLAB UnRAR; WinRAR GUI устанавливать не нужно.

## Выходные файлы

Оба файла сохраняются в `sql\base` и не добавляются в git (`.gitignore` исключает `*.sql`):

| Выходное имя | Имя в upstream-архиве | Размер распакованного SQL | База MySQL |
|---|---|---:|---|
| `ADB_world.sql` | `ADB_735.10_world.sql` | 366,619,372 байт (~350 MiB) | `world` |
| `ADB_hotfixes.sql` | `ADB_735.10_hotfix.sql` | 126,317,838 байт (~120 MiB) | `hotfixes` |

Оригинальный архив около 84 MiB, то есть скачивается существенно меньше, чем два необработанных дампа.
Файлы остаются в `sql\base` после импорта для следующего запуска. Удалите их вручную, если хотите освободить около 470 MiB; при следующем setup они скачаются повторно.
Проверка после импорта сверяет 11 обязательных world-таблиц и 3 hotfix-таблицы.
В данном upstream ADB таблица `battle_pet_species` существует, но содержит 0 строк; это нормальная
особенность релиза. Поэтому setup проверяет наличие её схемы, а наличие данных подтверждает по
`item_sparse` и `spell`. На тестовой MariaDB 10.11 импортированы все 222 world- и 330 hotfix-таблиц;
проверка таблиц и обязательных строк прошла.

## Про build 26124

Текущий LEGIONFORGE настроен на WoW 7.3.5 client build 26124. Официальный ADB_735.10 релиз помечен AshamaneCore как `Final before BfA`; кодовая ветка AshamaneCore указывает 7.3.5.26972. Поэтому это проверенная чистая Legion-база от upstream Ashamane, но не гарантированно точный SQL snapshot на дату build 26124. Она используется здесь потому, что LEGIONFORGE происходит от AshamaneCore и исходный downloader этого проекта также ссылался на ADB_735.10.

Если ядро в вашей сборке требует точный исторический контент именно на 26124, нужен дамп соответствующей ревизии. Не подменяйте его непроверенными архивами. Текущая проверка `check_database_schema.ps1` проверяет требуемые таблицы и данные перед применением патчей и стартом сервера.

## Ручное получение / повторы

При обычной установке достаточно `setup.bat`; скачивание и импорт запускаются только при пустых базах. Вручную вызвать загрузчик можно так:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\get_databases.ps1
```

Загрузчик проверяет уже имеющиеся `ADB_world.sql`/`ADB_hotfixes.sql` и прежние имена `ADB_735.10_world.sql`/`ADB_735.10_hotfix.sql`. Сжатый официальный RAR кешируется в `setup_tmp\ADB_735.10.rar`.

Дамп world/hotfix импортируется только в пустую соответствующую БД: существующие данные не перезаписываются. Поэтому, если вы раньше импортировали собственный большой world/hotfix дамп и хотите заменить его чистым ADB, сначала остановите сервер и сделайте резервную копию; затем очистите/пересоздайте только базу (или базы), которую хотите заменить. При следующем `setup.bat` пустая база будет заполнена ADB автоматически. Не удаляйте auth/characters, если хотите сохранить учётные записи и персонажей.

## Локальные требования

В `sql\base` вручную требуются только небольшие `auth.sql` и `characters.sql`. `get_databases.ps1` формирует ADB-файлы автоматически. URL можно переопределить переменной окружения `LEGIONFORGE_DATABASES_URL` (ZIP с SQL `ADB_735.10_world.sql`/`ADB_735.10_hotfix.sql` или с конечными именами).
