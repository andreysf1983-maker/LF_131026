LEGIONFORGE 7.3.5 (client build 26124) - sql\base
=================================================

Вручную положите сюда только две небольшие схемы:

    auth.sql          (~66 КБ)    -> база auth
    characters.sql    (~14 МБ)    -> база characters

Дамп игрового мира больше вручную не нужен. Если базы world и/или hotfixes пусты,
setup.bat автоматически скачивает официальный AshamaneCore ADB_735.10 (~84 МиБ),
проверяет SHA-256, распаковывает его официальным RARLAB UnRAR и получает:

    ADB_world.sql       366 619 372 байт (~350 МиБ) -> база world
    ADB_hotfixes.sql    126 317 838 байт  (~121 МиБ) -> база hotfixes

Чистые дампы сохраняются здесь после первого скачивания, повторно не загружаются.
Можно удалить их, чтобы освободить место; при следующей установке они будут загружены снова.
Исходные файлы `world.sql` и `hotfixes.sql` из вашего большого дампа setup не использует.

Важно о версии: источник - официальный выпуск ADB_735.10 "Final before BfA" AshamaneCore
(снимок Legion 7.3.5 upstream, позднее клиента build 26124). Это чистая известная база Ashamane,
а не строго зафиксированный дамп на build 26124. Если нужен именно исторический снимок 26124,
нужен официальный выпуск ADB соответствующего build; не подменяйте его случайными дампами.

Если дампы ADB уже имеются вручную, поддерживаются точные имена `ADB_world.sql` и
`ADB_hotfixes.sql` (а также старые имена `ADB_735.10_world.sql` / `ADB_735.10_hotfix.sql`).

Все `*.sql` в этой папке исключены из git из-за размера. Подробности: `docs\ADB_DATABASES.md`.
